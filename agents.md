# AGENTS

## Design and planning

When designing or planning anything (a new project, a large feature, a migration, a rewrite), you MUST follow [`implementation_planning.md`](implementation_planning.md).

## Version control and CI

Projects use GitHub for source hosting and GitHub Actions for CI. Plans and implementations must account for this: keep work in git, use branches and pull requests, and set up CI workflows (build, tests, checks) so that every change is verified automatically.
